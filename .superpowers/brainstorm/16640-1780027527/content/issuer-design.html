Issuer App — Design

Issue credentials: onboard keys/certificates, configure credential data, generate offers

Features & Screens

Issuer — Application Shell
Issuer App  |  Dashboard  |  Issue Credential  |  Active Offers  |  Config
Onboarding Status

Shows current issuer state. For mDoc: IACA cert + DS cert status. For SD-JWT/JWT: issuer key + DID. "Onboard" button if not yet configured.

mDoc: IACA ✓   DS ✓
SD-JWT: Key ✓   DID ✓
JWT VC: Key ✓   DID ✓
Issue New Credential

Select format (mDoc / SD-JWT / JWT VC), fill in credential data, configure selective disclosure (for SD-JWT), click Issue. App calls the appropriate POST /openid4vc/{format}/issue endpoint.

mDoc
SD-JWT
JWT VC

Each format shows a different data entry form based on the format's schema (mdoc: namespaces + fields, SD-JWT: flat key-value + SD toggles, JWT VC: credential type + JSON body)

Generated Offer

After issuance, shows the resulting offer URI. Copy button. Also shows the offer content via GET /credentialOffer?id=.
