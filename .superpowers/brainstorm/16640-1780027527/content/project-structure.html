Shared Conventions

API Client Pattern

Each app has its own src/api/ with typed fetch functions mirroring the shell scripts. All use the same pattern:

  • Base URL from .env (defaults to localhost)
  • Token from localStorage, auto-attached as Bearer
  • Consistent error handling with toast notifications
  • Format-specific payload builders (mdoc / sd-jwt / jwt-vc)

UI Conventions

  • Minimal CSS — no framework, just clean design
  • Each app on its own port (5173, 5174, 5175)
  • Start script: npm run dev in each dir
  • Shell script to start all three: start-all.sh
