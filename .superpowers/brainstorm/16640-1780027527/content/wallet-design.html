Wallet App — Design

The user's credential wallet: register/login, manage credentials, receive offers, respond to verification requests

Login Screen

Email + Password form. Also offers Registration toggle. On submit: POST /auth/login → stores token in localStorage.

Credentials Dashboard

Lists all held credentials. Each card shows type (mDoc/SD-JWT/JWT), issuer, dates. Click to view details.

Claim Credential (Offer)

Text input for credential offer URI. Calls POST /exchange/useOfferRequest → adds credential to wallet. Shows a success card with new credential details.

Verification Request

Paste auth request URL. App resolves, matches credentials, shows what will be shared, user approves. Then fulfills presentation.

Keys & DIDs

Read-only view of wallet keys (GET /keys) and DIDs (GET /dids). Table display with key IDs, DID strings, aliases.
